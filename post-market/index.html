End-to-End Data Engineering Project

Market Intelligence Data Warehouse

Local ETL pipeline that ingests, normalizes, and models LATAM tech job postings into a Star Schema Data Warehouse on SQL Server Local (JobMarketDB), with phase quality gates, Candidate Matching, and CSV export for BI.

SQL Server

Local JobMarketDB (port 1433, ODBC 18) with staging, warehouse & analytics schemas.

Python ETL

Incremental SerpAPI ingestion (RUN_SERPAPI_INGEST), Parquet staging & skill regex.

10 Phases

Orchestrated via main.py (--all / --phase) with data quality & CSV audit gates.

Star Schema

Fact table, M:N skill bridge & dimensions exported to data/3_csv for Power BI.

Data Architecture & Pipeline Flow

1. Ingestion

Flag-driven SerpAPI or local JSONs in data/1_raw + state tracking.

2. Staging

Role/skill classification, deduplication & vacantes_staged.parquet.

3. Staging DB

T-SQL landing tables in local JobMarketDB (staging schema).

4. Star Schema

Set-based load into warehouse dims, fact & skill bridge tables.

5. Analytics & CSV

SQL views, Candidate Matcher & reconciled CSVs in data/3_csv.

Core Business Rules & Features

Deduplication & Snapshots

Deterministic job IDs in Parquet staging and snapshot uniqueness per source, job ID, and capture date in SQL Server.

Role & Skill Taxonomy

Classifies roles (primary, secondary, legacy_leverage) and extracts skills from YAML taxonomies.

Candidate Matcher & DQ

Scores role alignment, skill match, and geographic/language accessibility while auditing integrity and CSV exports.
